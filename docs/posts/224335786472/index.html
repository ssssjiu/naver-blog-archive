그것은 실리카겔 신곡이 나왔다는 뜻. 냐냐냐냐냐 고양이가 되어버려. 그런 부름. 아무튼 오늘도 휴출해서 이챠이챠 했다는 내용입니다. 음, 일터가 좀 그런 것 같은데. 나 너무 외로워.

​

음, 괴테는 모든 것을 말했다. 너무 좋은 이야기입니다. 나중에 또 한 번 읽어야지 싶어요. 그 카페에 다시 가서 그런 시간을 보내는 건 어떤가. 내 마음은 어떠한가? 이제 더는 앞서갈 필요가 없어요. 슬픈 생각, 안 아픈 생각. 멀어져가는 심상.

​

휴출 다녀오고 좀 잤더니 어제랑 비슷하게 4시에 기상해버린. 부랴부랴 대청소는 못 해도 방 정리 어느 정도 해두고는 저녁에는 피자 쿠폰으로 시켜묵고. 오늘은 뭐 별 거 없네용. 어제의 여운이 진하게 남아있습니다. 아마 새벽에 나갈 것 같아서 말입죠. 음, 나는 내가 별로 안 좋은데 노력해야지 싶습니다. 내일은 글좀 끼적입니다. 으랴으럇.
