옆집 천사 애니로 정주행 완료. 그리고?

2026-10-05T20:17:01+09:00 하소 보존 버전 1
네이버 원문 보기 ↗

​

필자는 순애와 정말 맞지 않는다는 것을, 모르는 척 해왔지만 이젠 어쩔 수 없네. 결국, 선남선녀가 꺅꺅우후후후 우끼끼 하는 게 다인 내용이라는 것을... 그렇다면 못난 사람으로 드리겠습니다! 필요없어! 아무튼, 보면서 치아가 다 썩어버릴 것 같으면서도 조금 낡은 느낌을 받았으니, 재미는 있었다. 내년 2분기에 2기 나오는데 흠흠... 이제 커플 됐으니까 더 치아 부식 속도가 빨라지게, 아주 더 빠르게. 아무튼, 이렇게 모에한 히로인을 만드려면 정신이 이상해야 한다는 결론이 나왔다. 그래도 괜찮아 귀엽잖아? 그냥 천사더구먼.

​

흠... 결국, 키크고 잘생기고 다른 스펙도 평균 이상인 남캐들이 사연있는 미소녀 캐릭터 만나서 풀어가는 이야기 => 이러면 순애 말고 다른 것고 거의 다 비슷?할 수는 있으나 순애들이 대부분 이랬던 것? => 그럼 죽어. 보지 마!

​

사실 현실 순애가 창작물 저리가라 수준이기도 해서 좀... 나는 일단 순애와 연애에 적합하지 않은 구조, 빰빰빰 빰빠빰 빠라밤. 이번 습작 주인공 안 행복하게 만들어 줘야겠다. 그래도 농밀한 하루 보냈으니까... 아, 여기저기 아프고 쉴 곳이 없네. 가시나무 새야. 원작 소설아 조오금 궁금해졌다가 안 보는 게 나을 것 같다는 결론. 빠라밤.
