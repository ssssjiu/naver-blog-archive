주말에 새로운 술을 접해볼까 해서 지인에 추천받은 술인

​

​

헤네시를 구매하였습니다. 주류 할인점에 간 김에 제가 좋아하는 스카치 위스키인 조니 워커도 하나 사볼까 해서 자주 못 봤던 조니 워커 더블 블랙 친구도 질러보았습니다.

​

평소에 위스키인 발렌타인이나 조니 워커만 마셔봤던지라 다른 종류의 술인 브랜디에 관심을 가지게 되었습니다.

주류 할인점에 대략 10만원 안쪽으로 구매가 가능하고, 입문용으로 좋다는 글이 많아서 망설임 없이 선택하였네요.

​

​

전부 다 마셔볼 수는 없겠지만 100만원 이내의 제품들은 한 번 다 마셔볼 계획입니다. 아직 구매만 하고 개봉은 안 해서 기대가 됩니다아.

​

다음은 X.O가 되겠네요. 마셔본 후에 다시 후기 올려보겠습니다.
