9월 27일 과연 중요한 건

2026-10-05T20:17:21+09:00 매일 기록 원본 확인됨 보존 버전 1
네이버 원문 보기 ↗

​

음, 기린성에 가지 못 하고 기린 생맥을 저렴하게 마시지 못 해서 스으으을프지만 아무튼 좋습니다. 대신 오랜만에 방문한 중식당이 정말 괜찮았거든요. 가격도 엄청 저렴하고, 볶음밥 7천원에 너무나도 훌륭한 퀄리티, 이건 만족하지 않을 수가 없었습니다. 짜장면은 무려 5000원, 홀에서 먹는 가격이라고 해도 엄청 저렴했죠. 상급 가성비 스멜~

​

친구가 포켓몬 카드 산다고 해서 무인 카페들 막 돌아다니고 거의 7군데는 돌아본 것 같습니다. 다행히 건진 건 있는데 결과물은 어떨지 모르겠네요. 좋은 것이 나왔기를 바라며. 오늘따라 생맥이 그리운 하루였습니다. 다음에는 꼭 마시겠다, 키이이이린.

​

X스, 과연 중요한가? 뜬금없지만 얘기해 봅니다.

​

​

아아... 아아! X스!!! X스 하고 싶은가!? 아니라고 할 수는 없겠지. 싸우고 야스하고 싸우고 야스하고 그냥 하고 막 하고 진짜 막 눈만 마주치면 하고 그냥 하고 하루종일하고 뇌세포가 데미지를 입을 때까지 어쩌구 저쩌구. 뭐, 저는 그렇게 X스를 좋아하지는 않습니다. 동인지는 무지하게 많이 봤지만. 아무튼, X스? 확실히 하기 전과 후는 차원이 다릅니다. 마치 삶의 차원이 하나 더 상승한다고 봐도 무방합니다. 너무 호들갑 같지만, 거의 비슷합니다. 근데, 전 차원이라는 것을 제대로 이해하고 있지는 않습니다. 뭐요?

​

예쁘다 => X스

귀엽다 => 약한 X스

꼴린다 =>> X스! X스으으으으!

​

이렇게 볼 수 있겠죠. 하지만, 꼴린다는 표현... 실제로는 그렇게 많이 쓰이지는 않습니다. 가볍게 취향이나 무언가 창작물을 얘기할 때는 나올 수 있으나, 실존 무언가에게는 쓰면 실례니까요. 사실 엄청난 칭찬이기도 한데, 그렇게 받아들이지 않죠, 그렇게 생각하기 어렵기도 한게 사실이고요. 갑자기 어떤 여성분이 저 한테 오셔서 "개꼴리게 생기셨네요?" 이러시면... 그냥 무서울 것 같네요. 역시 지양하는 게 맞는 것 같습니다. 마냥 기분이 나쁘지는 않을 것 같다만... 상황이랑 상대방 호감도가 중요하지. 그래, 결국 얼굴이 다 한다니까? 다시 태어나도 안 된다고.

​

음, X스를 하자는 건 좀 그렇고, 할 수 있으면 해보십시오. 피임만 잘 하면 되지 않겠습니까? 쾌락을 추구하는 건 당연한 일이고 적정선을 지켜가며 추구하는 건 삶을 건강하게 만들 수도 있습니다! 아니라고요? 그럼 어쩔 수 없고요. 아마 제대로 된 X스를 안 해봐서 그런 걸지도 모릅니다. 근데, 저도 X스가 사실 뭔지 잘 모릅니다. 일단 크리스마스 때 많이 하더라고요? 콘돔도 많이 팔리고, 방도 잡기 어려운 날이니까 말이죠. 그래서 올해는 어떻게 되냐구요? 가능하면 좋은 술 마시면서 방송하거나 산책할 겁니다. 아니면 둘 다 하면 되겠군요? 천재로군요.

​

왜 갑자기 이런 얘기를 하느냐? 모르겠습니다. 어디에도 없는 무언가를 찾는 건 매일 해오던 일이니까요. 오늘 너무 이상한 꿈을 꿔서 그런 것 같습니다. 그 꿈을 얼마를 주고 샀는지는 몰라도, 범상치 않았기에 저는 눈물이 찔끔날 뻔했고 헛웃음을 내뱉으며 과거를 비난했습니다. 용서하지 않겠다, 서두르고 서툴렀던 건방진 나.

​

뭐, 연인 사이면 X스는 당연히 하겠죠. 당연하게 하란 말이야. 더 나아가서 가정도 이루고 말이죠. 하지만, 그러기 어렵죠. 이젠 꿈처럼 다들 희미해져서 아무 것도 알아볼 수가 없단 말이야, 그래서 선명한 것들은 이미 형태가 정해져 있고 전개와 결말까지 다 정해져 있어. 그런 얘기더라고. 그러니, 과거에 분노하지 말고 담담하게 살아가세. 응.
